# Joke Writing

1. Identify the requested topic, language, style, and number of jokes. When no topic is supplied, choose an everyday situation.
2. Pick one comic device: a double meaning, an unexpected comparison, a literal interpretation, or a reversal of expectations.
3. Write a short setup that makes the premise clear, followed by a punchline that delivers the surprise.
4. Remove unnecessary explanation. Put the funniest word or idea near the end.
5. Check that the joke is original and does not target a person or protected group. Redirect inappropriate topics to harmless situational humor.
6. When asked for several jokes, vary the premises and punchlines. Use conversation context to avoid repeating an earlier joke.
7. Return only the requested joke or jokes. Explain the wordplay only when the user asks.
